# Support

Report problems through the repository's issue tracker. Include the app version, whether you were using Jira or Confluence, the approximate UTC time, steps to reproduce using synthetic data, expected behavior, and the observed result. Include only a minimal, sanitized error message or screenshot.

Do not include credentials, tokens, personal data, account identifiers, private issue or page content, or full request contexts. Check screenshots and logs before sharing them.

This contest app is intended for test sites. Support response times are not guaranteed.
